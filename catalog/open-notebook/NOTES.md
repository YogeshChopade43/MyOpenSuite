# Open Notebook

Upstream: https://github.com/lfnovo/open-notebook · images `docker.io/lfnovo/open_notebook:v1-latest`,
`docker.io/surrealdb/surrealdb:v2` (from upstream `docker-compose.yml`).

- Only the UI port is published. `API_URL=http://localhost:7804` makes the browser call the UI's own
  URL; Next.js forwards `/api/*` to the API (port 5055) inside the same container. Uploads through this
  path are capped at 100 MB.
- The SurrealDB password and the encryption key for stored provider keys are generated by MyOpenSuite
  (see **Credentials**); you never need to type them.

## AI provider

Open Notebook needs an LLM for chat, summaries and podcasts. Open it → **Settings** → add a provider
(OpenAI, Anthropic, OpenRouter, Ollama, …) and paste its key.

## Manual check

Create a notebook and add a web page as a source (works without an AI key). With a key: ask a question
about the source.
