# AppFlowy

Upstream: https://github.com/AppFlowy-IO/AppFlowy-Cloud — `docker-compose.yml`, `deploy.env` and
`nginx/nginx.conf` from the main branch (2026-11-02). Images use `:latest`, as upstream's compose does:
the GitHub "latest release" (0.9.64) is far behind the published images (0.20.x), and the images are
not tagged with a common version, so pinning one set consistently is not possible.

## How this differs from upstream

- **nginx is the main service** (`appflowy`), built from `./nginx`:
  - `resolver` is filled in at start from `/etc/resolv.conf` (`10-resolver.sh`). Upstream hard-codes
    Docker's `127.0.0.11`, which does not exist under Podman.
  - TLS, the pgAdmin route, the MinIO console route and the metrics server are removed.
  - CORS only allows `http://localhost:7807` (upstream reflects any origin).
- **MinIO → RustFS.** MinIO no longer publishes community images (Docker Hub repo gone, quay.io
  requires login). `docker.io/rustfs/rustfs:1.0.4` is S3-compatible and runs under the service name
  `minio`, so AppFlowy's config is unchanged.
- **No `ai` service** (needs an OpenAI key); `AI_ENABLED=false`.
- Email sign-up is auto-confirmed (`GOTRUE_MAILER_AUTOCONFIRM=true`); there is no SMTP.
- Passwords and secrets (Postgres, GoTrue JWT, S3, admin password) are generated by MyOpenSuite.

## First open

Open the app → **Sign up here** → your email and a password (no confirmation email is sent). That
account gets your workspace.

**Self-hosted AppFlowy includes one free member seat.** The first account that signs up takes it; a
second sign-up fails with "Your AppFlowy license has reached a limit". Use your real email for that
first account. (Uninstall with "Also delete data" resets it — and deletes all pages.)

`admin@example.com` (password in **Credentials**) is a *system admin* for the admin console at
http://localhost:7807/console. AppFlowy deliberately gives it no workspace, so don't use it for notes.
The end-to-end test only signs in as this admin, so it never uses up the free seat.

## Manual check

Sign up, create a page, type some text, reload — the text is still there.
